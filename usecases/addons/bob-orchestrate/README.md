## 🤖 Objetivo

Neste laboratório, o Bob, seu parceiro de desenvolvimento de software com IA, vai ajudá-lo a incorporar seus agentes IA em seu website.

## 🤔 O Problema

Usuários low-code, usuários de negócio e product managers conseguem construir rapidamente agentes poderosos no **watsonx Orchestrate** sem programar. No entanto, transformar esses agentes em um sistema de produção, ou mesmo em um protótipo end-to-end, requer que desenvolvedores front-end construam UIs. Até mudanças simples—adicionar uma nova aba, conectar um painel de chat básico, ou enviar inputs para um agente—podem levar dias para desenvolver e testar quando feitas manualmente, e requerem compreensão adequada das APIs, JavaScript, integração HTML, etc. Isso desacelera a iteração sobre requisitos e atrasa o feedback de stakeholders reais que precisam ver e clicar através de uma experiência realista.

## 🎯 A Solução

Este laboratório mostra como usar o IBM Bob e vibe coding para rapidamente adicionar uma nova aba a uma UI de aplicação existente e conectá-la a um agente do **watsonx Orchestrate** já construído. O objetivo é ajudar desenvolvedores não-tradicionais e equipes de produto a moverem de "ideia de agente" para "protótipo clicável" em minutos, para que possam validar a implementação do agente, refinar prompts e alinhar sobre UX antes de se comprometer com uma implementação completa.

## 📋 O que Você Vai Realizar

Ao completar este laboratório, você irá:

- **Criar uma nova aba funcional** em um website existente para estender capacidades voltadas ao usuário
- **Gerar um `server.py` completo** que habilita autenticação segura e integração perfeita de API com os agentes IA
- **Integrar um agente pré-construído do watsonx Orchestrate** diretamente no arquivo `server.py`
- **Habilitar funcionalidade para acionar o agente** a partir da aba recém-criada, conectando a UI aos agentes IA

## 📈 Valor de Negócio

Ao combinar o construtor de agentes low-code do **watsonx Orchestrate** com a **geração de código do IBM Bob**, equipes podem explorar mais ideias com significativamente menos esforço de engenharia.

- **Prototipagem mais rápida**: Use prompts em linguagem natural mais um pequeno snippet de referência para gerar a nova aba de UI e código de integração, reduzindo drasticamente o tempo de conceito a demo funcional
- **Usuários de negócio empoderados**: Product managers e especialistas de domínio podem dirigir mudanças de UI e workflow através do Bob com codificação manual mínima, enquanto permanecem alinhados com a base de código existente
- **Melhores requisitos**: Protótipos realistas e precoces ajudam stakeholders a rapidamente entender o que um agente pode e não pode fazer, levando a requisitos mais claros e menos ciclos de retrabalho
- **Reuso para produção**: Uma vez que o protótipo é validado, os mesmos padrões de aba e integração gerados pelo Bob podem ser endurecidos e estendidos para produção, ao invés de reescrever tudo do zero
